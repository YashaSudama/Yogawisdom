# WordPress Child Theme

## About the project

A custom WordPress child theme developed to extend the functionality and design of a parent theme without modifying its core files.

## Technologies

* WordPress
* PHP
* HTML5
* CSS3
* JavaScript
* WooCommerce (if applicable)

## Features

* Custom page templates and theme components
* Custom PHP functionality
* Responsive layout and styling
* JavaScript interactions
* WooCommerce customization (if applicable)

## Installation

1. Install WordPress.
2. Install the required parent theme.
3. Copy this folder into `wp-content/themes/`.
4. Activate the child theme in WordPress Appearance → Themes.

## Notes

This project requires the parent theme specified in `style.css`. The parent theme is not included in this repository.
